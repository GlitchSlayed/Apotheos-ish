# Summit

A modern, vanilla-friendly Fabric mod that reimagines [Apotheosis](https://github.com/Gravestone43/Apotheosis) for Minecraft 26.3.

## Features

- **Spawner Tweaks** — Configurable spawner mechanics including delays, spawn counts, player ranges, redstone control, and mob state overrides.
- **Enchanting Tweaks** — The Capturing enchantment, which gives players a chance to drop a spawn egg when killing a mob.
- **Difficulty Scaling** — Mobs scale in difficulty as the player grows more powerful (30-40% stronger when the player is 100% stronger).

## Dependencies

- [Fabric API](https://fabricmc.net/)
- [ModMenu](https://github.com/FabricMC/modmenu)
- [YACL (YetAnotherConfigLib)](https://github.com/isXander/YetAnotherConfigLib)

All settings are configurable in-game via YACL.
